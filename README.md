В общем документе каждый вопрос оформлен последовательно: **формулировка → где найти → что рассказать → определения, утверждения, формулы и выводы**. Добавлено оглавление с переходами. Документ составлен на основе отдельных TeX-ответов; нумерация формул и ссылки на источники сохранены. Текущая сборка содержит 56 страниц.

## Сборка XeLaTeX

Нужны TeX-дистрибутив с XeLaTeX (проект собирался в MiKTeX) и шрифт **Times New Roman**. Пакеты, используемые документами, указаны в преамбулах; среди них `fontspec`, `babel`, `amsmath`, `amssymb`, `graphicx`, `hyperref`, `mathrsfs` и `cancel`.

Общий документ собирается из корня репозитория:

```powershell
xelatex -interaction=nonstopmode -halt-on-error porous_all_questions.tex
xelatex -interaction=nonstopmode -halt-on-error porous_all_questions.tex
```

Текст ответов встроен в общий `.tex`. Рисунки вопроса 5 подключаются из `tex_результат/5/figures/`, поэтому при переносе документа нужно сохранить эту папку и её расположение.

Пример сборки отдельного фрагмента и ответа:

```powershell
Set-Location tex/10
xelatex -interaction=nonstopmode -halt-on-error main.tex
xelatex -interaction=nonstopmode -halt-on-error main.tex
Set-Location ../../tex_результат/10
xelatex -interaction=nonstopmode -halt-on-error 10.tex
xelatex -interaction=nonstopmode -halt-on-error 10.tex
```

Два прохода нужны для оглавления и перекрёстных ссылок.

## Обновление общего документа

После изменения отдельных ответов можно пересоздать общий TeX из корня проекта:

```powershell
python tex/build_all_questions.py
```

Скрипт использует `tex_результат/N/N.tex`, добавляет указатели источников и планы рассказа, проверяет метки, нумерацию формул и пути к рисункам. Он **перезаписывает** `porous_all_questions.tex`: ручные изменения общего файла следует предварительно сохранить. После генерации нужно снова выполнить XeLaTeX дважды.

Для вспомогательных операций с изображениями и PDF в скриптах используются Python, PyMuPDF (`fitz`) и Pillow; для чтения DjVu — Node.js и локальная библиотека DjVu.js. Для самой сборки TeX Python и Node.js не требуются.

## Источники и правила работы с текстом

Основные материалы: Н. Е. Леонтьев, «Основы теории фильтрации» (2017); К. С. Басниев и др., «Подземная гидравлика» (1986); Г. И. Баренблатт, В. М. Ентов, В. М. Рыжик, «Теория нестационарной фильтрации жидкости и газа» (1972); А. Г. Куликовский, Е. И. Свешникова, «Нелинейные волны в упругих телах» (1998).

- В отдельных ответах используются цитаты перенесённого в TeX текста с указанием источника и печатных страниц. В общем документе к ним добавлены краткие планы рассказа.
- Печатная страница книги и номер страницы PDF/DjVu различаются; точное соответствие указано в комментариях и README фрагментов.
- Постановка о трубе-источнике в вопросе 5 выделена как отдельный фрагмент рукописного конспекта; она не приписывается учебнику Леонтьева.
- Возможные опечатки и несогласованности исходных изданий сохранены и перечислены в README соответствующих вопросов. Набор текста не означает исправление математического содержания оригинала.
- В вопросе 9 отмечен дополнительный штрих в формуле (8.42), требующий сверки с более чётким оригиналом.

Подробные границы каждого выбранного фрагмента и результаты проверки следует смотреть в его README.
