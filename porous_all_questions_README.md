# Общий материал по вопросам 1–12

Основной файл: porous_all_questions.tex. Составлен только на основе tex_результат/1/1.tex … tex_результат/12/12.tex. Для каждого вопроса: формулировка, краткое «Где найти», план «Что рассказать», затем определения, утверждения, формулы и выводы из готового ответа. Оглавление с переходами.

Текст всех ответов встроен в общий файл. Сохранены 102 цитатных фрагмента, 93 нумерованные формулы, ссылки на книги, исходные обозначения, сноски и замечание о неясном штрихе в вопросе 9. Изображения вопроса 5 подключаются из tex_результат/5/figures/; для сборки нужно сохранить эту папку относительно основного файла. Дополнительные формальные теоремы не добавлялись: в блоках воспроизведены утверждения, имеющиеся в ответах. План рассказа — редакционная навигация по этим материалам.

Сборка из основной папки проекта:

```powershell
xelatex -interaction=nonstopmode -halt-on-error porous_all_questions.tex
xelatex -interaction=nonstopmode -halt-on-error porous_all_questions.tex
```

Шрифт Times New Roman. Результат — porous_all_questions.pdf, 56 страниц.

Проверка: все 12 исходных тел ответов сохранены полностью (с изменением только путей изображений и уровня заголовка фрагмента конспекта). Нет повторных меток, неопределенных ссылок, отсутствующих символов и переполнений строк. Визуально проверены все страницы, оглавление, начала вопросов и рисунки. Новая сверка с книгами в этой операции не выполнялась: использованы уже подготовленные ответы, включая сохранённые особенности оригинала.

Повторная генерация после изменения отдельных ответов: python tex/build_all_questions.py. Сценарий перезаписывает сводный TeX, поэтому ручные изменения в нём нужно предварительно сохранить отдельно.
