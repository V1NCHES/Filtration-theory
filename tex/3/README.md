## Сборка

Из этой папки:

```powershell
xelatex -interaction=nonstopmode -halt-on-error main.tex
xelatex -interaction=nonstopmode -halt-on-error main.tex
```

Ответ собирается аналогично из папки `tex_результат`, командой `xelatex -interaction=nonstopmode -halt-on-error 3.tex` в два прохода.

Использованы доступные Times New Roman, Arial, Courier New и математические шрифты AMS/LaTeX. Для зачёркнутого слагаемого, присутствующего в оригинале при выводе уравнения движения, подключён пакет `cancel`.
