# Ответы по вопросам спецкурса

Каждый ответ хранится в собственной папке: `1/1.tex`, `2/2.tex`, `3/3.tex`, `4/4.tex` и далее по номеру вопроса. Рядом находится собранный PDF и скрипт отбора цитат.

Для каждого следующего ответа в начале документа обязательно указывать:

1. Номер и полную формулировку вопроса пользователя.
2. Краткий источник: автор, название книги, издание, глава, параграфы и печатные страницы; только сведения, установленные по исходным материалам.
3. Далее — ответ из дословных цитат перенесённого TeX, с формулами и ссылкой на источник после каждой цитаты.

Вводный блок с формулировкой вопроса и источником добавляется по отдельному указанию пользователя. Он не является цитатой учебника. Остальной ответ сохраняет ранее согласованные правила цитирования: без пересказа и самостоятельных исправлений.

Полные перенесённые параграфы и изображения оригинала находятся в соседней папке `../tex/номер/`.

Вопросы 1–4 обновлены: добавлены формулировки и источники, исправлены пути скриптов для размещения в номерных папках, PDF пересобраны в XeLaTeX. После добавления вводного блока количество страниц: 1 — 4; 2 — 5; 3 — 8; 4 — 4.


Вопросы 6–9: каждый ответ размещён в отдельной папке своего номера; полные фрагменты — в ../tex/6 … ../tex/9. Вопросы 6–8: Леонтьев, §§ 9, 11, 12; вопрос 9: Басниев и др., гл. 8, §§ 1, 2, 4. Неясность (8.42) указана в материалах вопроса 9.


Вопросы 10–12: ответы находятся в отдельных папках 10, 11, 12; полные выбранные фрагменты — в ../tex/10, ../tex/11, ../tex/12. Источники: Басниев (10); Баренблатт, Ентов, Рыжик (11); Куликовский и Свешникова, Басниев, Баренблатт и др. (12). Точные диапазоны и особенности печатного оригинала перечислены в README каждого фрагмента.
