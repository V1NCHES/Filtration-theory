# Ответ на вопрос 11

11.tex — редактируемый ответ из дословных цитат с формулами. В начале указаны вопрос и источники; после каждой цитаты — книга, глава, параграф и печатные страницы.

Полный выбранный материал: ../../tex/11/main.tex и chapter.tex. Точный объём, источники, проверка и особенности печатного оригинала: ../../tex/11/README.md.

Сборка: xelatex -interaction=nonstopmode -halt-on-error 11.tex дважды. Шрифт Times New Roman. Документ успешно собран и визуально проверен.
