# Ответ на вопрос 5

`5.tex` — самостоятельный ответ с полной формулировкой вопроса и краткими сведениями об источниках в начале. Основная часть — девять дословных цитат из `../../tex/5/chapter.tex` (Леонтьев, 2017, глава II, § 8); после каждой цитаты указаны печатные страницы. На отдельной странице включён разрешённый пользователем фрагмент рукописного конспекта из `../../tex/5/notes.tex`, страницы PDF 14–15, с отдельной атрибуцией. Рисунки находятся в `figures/`.

`5.pdf` — собранный ответ, 6 страниц, вёрстка проверена.

Из этой папки выполнить дважды:

```powershell
xelatex -interaction=nonstopmode -halt-on-error 5.tex
xelatex -interaction=nonstopmode -halt-on-error 5.tex
```

`python build_answer.py` заново отбирает цитаты из TeX и копирует нужные рисунки; команда перезаписывает `5.tex`.

Плотина и её граничные условия взяты из учебника; подземная труба-источник с неизвестной свободной границей — из конспекта. Задача об отводе воды к дренажной щели не представляется как задача об оросителе. В рукописи буквальное название «кротовый ороситель» отсутствует; сохранена именно доступная постановка с источником 2Q и схемами областей.

Читаемые несогласованности формул оригинала сохранены. Их перечень и границы переноса см. в `../../tex/5/README.md`. Неразборчивых перенесённых мест нет. Статус: выбранные фрагменты полностью обработаны, документ собран и визуально проверен.
